# Marks

The MH monogram alone. `mh-mark` is lime (#c2f852) and needs a dark ground; `mh-mark-black` is ink (#0b0d0a); `mh-mark-white` is white (#ffffff) and needs a dark ground. `mh-app-icon` is lime on an ink square, and `mh-app-icon-lime` is the inverse: use these for avatars, app icons and favicons.
