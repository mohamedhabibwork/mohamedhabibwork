# MH social & multi-use kit

All vector (text outlined). Generated by `build_social.py`.

| File | Use |
|---|---|
| `linkedin-banner` (1584×396) | LinkedIn profile background 1584×396. Profile photo covers the bottom-left; content sits right of it. |
| `x-header` (1500×500) | X / Twitter header 1500×500. Avatar overlaps bottom-left. |
| `facebook-cover` (1640×624) | Facebook cover 1640×624 (displays 820×312). |
| `youtube-banner` (2560×1440) | YouTube channel art 2560×1440; content inside the 1546×423 safe area. |
| `github-social` (1280×640) | GitHub repository social preview 1280×640. |
| `og-image` (1200×630) | Open Graph / link preview 1200×630 (site, LinkedIn & Slack shares). |
| `instagram-post` (1080×1080) | Instagram / LinkedIn square post 1080×1080. |
| `instagram-story` (1080×1920) | Story / Reel cover 1080×1920; content clear of the top and bottom 250px. |
| `video-background` (1920×1080) | Zoom / Teams / Meet background 1920×1080; logo top-right so your head doesn't cover it (it appears mirrored to you only). |
| `presentation-title` (1920×1080) | 16:9 title slide / thumbnail 1920×1080. |
| `avatar-dark` (800×800) | Profile picture: lime mark on ink. Circle-safe. |
| `avatar-lime` (800×800) | Profile picture: ink mark on lime. Circle-safe. |
| `avatar-light` (800×800) | Profile picture: ink mark on off-white. Circle-safe. |
| `email-signature` (600×160) | Email signature banner 600×160 (export @2x for retina). |
| `business-card-front` (1050×600) | Business card front, 3.5×2 in @300 dpi (add 0.125 in bleed at the printer). |
| `business-card-back` (1050×600) | Business card back, 3.5×2 in @300 dpi. |

`MH-Social-Kit.ai` holds every format as an artboard; `../MH-Brand-Kit.ai` adds the 11 logo variants (27 artboards).
