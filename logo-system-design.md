# Logo Design System — Mohammad Habib

## 1. Overview
This document defines the **logo design system** for **Mohammad Habib**, a **Senior Full Stack Developer**.
The goal is to create a modern, memorable, and scalable personal brand identity that reflects:

- Software engineering
- Clean architecture thinking
- Technical precision
- Modern web development
- Personal identity through initials

---

## 2. Brand Identity Summary
**Brand Name:** Mohammad Habib  
**Role:** Senior Full Stack Developer  
**Brand Personality:** Modern, technical, reliable, intelligent, clean, professional  
**Primary Audience:** Clients, recruiters, startups, tech teams, and business partners

---

## 3. Logo Goal
The logo should:

- Represent **Mohammad Habib** using the initials **M** and **H**
- Communicate a **technology-first identity**
- Be usable as a **full logo**, **icon**, **favicon**, and **social avatar**
- Work across both **light and dark backgrounds**
- Stay recognizable at small sizes

---

## 4. Logo Concept
The logo concept combines:

1. **Monogram:** the letters **M** and **H** merged into one geometric mark
2. **Code symbols:** angle brackets `< >` to reference programming
3. **Circuit/network lines:** to reflect software systems, connectivity, and engineering
4. **Blue gradient palette:** to express trust, innovation, and modern technology

### Concept Message
> “A developer identity that merges personal initials with code and system-thinking.”

---

## 5. Logo Structure
### 5.1 Primary Logo
The primary logo contains:

- The **MH monogram** as the central symbol
- Optional supporting text: **Mohammad Habib**
- Optional subtitle: **Senior Full Stack Developer**

### 5.2 Icon Logo
The icon-only version contains:

- Integrated **MH** monogram
- Left and right code brackets
- Top and bottom circuit-style connectors

### 5.3 Visual Breakdown
- **M:** dark navy geometric form on the left
- **H:** bright cyan / blue geometric form on the right
- **Top circuit lines:** symbolize digital networks and architecture
- **Bottom circuit lines:** symbolize system outputs / connected components
- **Angle brackets:** reinforce coding and development identity

## 8. Typography
### Primary Typeface Style
Recommended type styles:
- **Inter**
- **Poppins**
- **Manrope**
- **Montserrat**

### Typography Rules
- **Name:** bold or semibold
- **Subtitle:** medium or regular with larger letter spacing
- Keep typography clean, modern, and highly legible

### Example
- `Mohammad Habib` → Bold / Semibold
- `Senior Full Stack Developer` → Regular / Medium, tracking increased slightly

---

## 9. Layout Rules
### 9.1 Clear Space
Maintain clear space around the logo equal to at least:

- the width of one small circuit node, or
- **10% of the logo width**

No other elements should enter this space.

### 9.2 Minimum Size
#### Icon-only logo
- Minimum digital size: **32px × 32px**
- Recommended for favicon: **64px × 64px** and above

#### Full logo
- Minimum width: **180px** for digital use
- Recommended width: **280px+** for website usage

### 9.3 Alignment
- Horizontal version: icon on left, text on right
- Icon-only version: centered and balanced
- Maintain consistent spacing between icon and type

---

## 10. Background Usage
### Light Background
Preferred usage:
- White
- Light gray
- Very soft neutral backgrounds

### Dark Background
Use inverted or high-contrast version:
- Keep cyan/blue gradient vibrant
- Make dark navy shapes lighter if visibility is reduced

### Avoid
- Busy photographic backgrounds
- Low-contrast overlays
- Harsh red/orange backgrounds that clash with blue palette

---

## 11. Usage Guidelines
### Recommended Uses
- Personal website
- GitHub profile branding
- LinkedIn cover / profile assets
- CV / resume header
- Email signature
- Business card
- Presentation deck
- Watermark on project screenshots

### Do Not
- Stretch or distort the logo
- Change the proportions of M and H independently
- Rotate the logo unnecessarily
- Use random colors outside the brand palette
- Add shadows or effects that reduce clarity
- Remove important structural elements in the main version

---

## 12. Favicon and App Icon Guidelines
### Favicon
Use the **icon-only logo** with:
- Simplified spacing
- Strong contrast
- No name text

### Social Avatar

- Square format

- Do not rely on color alone to identify the mark
- For HTML usage, provide alt text such as:

```txt
Mohammad Habib logo, an MH monogram with code brackets and circuit lines
```
